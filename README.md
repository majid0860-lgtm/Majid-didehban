# AntiTheft Tracker — راهنمای نصب و استفاده

اپلیکیشن ساده‌ی ردیابی گوشی برای مواقع سرقت. با دریافت پیامک با متن **"موقعیت"** از یک شماره‌ی مورد اعتماد، گوشی سعی می‌کند GPS را روشن کند و لینک لایو لوکیشن را با پیامک به شماره‌ی دومی که مشخص کرده‌اید ارسال می‌کند.

⚠️ **این پروژه فقط برای نصب روی گوشی خودتان است.** نصب چنین برنامه‌ای روی گوشی شخص دیگری بدون اطلاع و رضایت او، در بیشتر کشورها جرم است (قوانین حریم خصوصی / شنود). مسئولیت استفاده با کاربر است.

---

## 0. ساده‌ترین راه: بیلد خودکار با GitHub Actions (بدون نصب Android Studio)

این پوشه الان یک پروژه‌ی گریدل کامل و آماده‌ی بیلد است. اگر نمی‌خواهید Android Studio نصب کنید، می‌توانید بگذارید سرورهای گیت‌هاب برایتان APK بسازند:

1. یک حساب رایگان در [github.com](https://github.com) بسازید (اگر ندارید).
2. یک ریپازیتوری جدید بسازید (Private یا Public، فرقی ندارد) — مثلاً به نام `AntiTheftTracker`.
3. تمام محتوای این پوشه (همه‌ی فایل‌ها و زیرپوشه‌ها، از جمله پوشه‌ی مخفی `.github`) را در صفحه‌ی ریپازیتوری با گزینه‌ی **"Add file > Upload files"** آپلود کنید (کشیدن و رها کردن هم کار می‌کند، نیازی به نصب Git نیست).
4. بعد از Commit کردن، به تب **Actions** بروید. یک workflow به نام "Build APK" به‌طور خودکار شروع به اجرا می‌شود (چند دقیقه طول می‌کشد).
5. وقتی سبز شد (تیک ✅)، روی همان اجرا کلیک کنید؛ پایین صفحه بخش **Artifacts** یک فایل به نام `AntiTheftTracker-debug-apk` می‌بینید — آن را دانلود کنید. داخلش فایل `app-debug.apk` است که همان چیزی‌ست که باید روی گوشی نصب کنید (طبق مراحل بخش انتقال و نصب).

⚠️ این تنظیمات را تست اجرا نکرده‌ام (این محیط چت به اینترنت/سرویس بیلد دسترسی ندارد)، پس احتمال کمی هست در اولین اجرا با خطای نسخه‌ی Gradle/Android SDK مواجه بشید. اگر این‌طور شد، فقط پیام خطای قرمز رنگ توی تب Actions رو کپی کنید و برام بفرستید تا اصلاحش کنم.

## 1. ساختار پروژه (روش جایگزین: Android Studio)

این پوشه شامل فایل‌های سورس کاتلین و منیفست است، نه یک پروژه‌ی کامل Gradle آماده‌ی بیلد. باید:

1. یک پروژه‌ی جدید در **Android Studio** بسازید: `File > New > New Project > Empty Views Activity` (زبان: Kotlin، Minimum SDK: 26 یا بالاتر پیشنهاد می‌شود).
2. فایل‌های این پوشه را در مسیر مشابه پروژه‌ی خودتان جایگزین/کپی کنید:
   - `app/src/main/java/.../MainActivity.kt`
   - `app/src/main/java/.../SmsReceiver.kt`
   - `app/src/main/java/.../LocationService.kt`
   - `app/src/main/res/layout/activity_main.xml`
   - `app/src/main/AndroidManifest.xml` (محتوای تگ‌های permission و کامپوننت‌ها را به منیفست خودتان اضافه کنید)
3. پکیج (`com.example.antitheft`) را با پکیج پروژه‌ی خودتان یکی کنید یا در تمام فایل‌ها جایگزین کنید.

## 2. وابستگی‌ها (build.gradle ماژول app)

```gradle
dependencies {
    implementation 'com.google.android.gms:play-services-location:21.3.0'
    implementation 'androidx.core:core-ktx:1.13.1'
    implementation 'androidx.appcompat:appcompat:1.7.0'
}
```

## 3. تنظیم اولیه بعد از نصب

1. برنامه را باز کنید، شماره‌ی «فرستنده‌ی مجاز» (شماره‌ای که پیامک "موقعیت" را می‌فرستد) و «گیرنده‌ی لوکیشن» (شماره‌ای که لینک موقعیت را دریافت می‌کند) را وارد و ذخیره کنید.
2. تمام مجوزهای درخواستی را تایید کنید: SMS، Location (هنگام استفاده + همیشه)، Notification.
3. بهینه‌سازی باتری برای این اپ را غیرفعال کنید (Settings > Apps > AntiTheft Tracker > Battery > Unrestricted) — در غیر این‌صورت گوشی‌های شیائومی/سامسونگ ممکن است سرویس را در پس‌زمینه ببندند.

### تنظیم اختیاری پیشرفته (برای روشن کردن خودکار GPS)

اندروید از نسخه 6 به بعد به اپ‌های عادی اجازه نمی‌دهد GPS را بی‌صدا (بدون تایید کاربر) روشن کنند. تنها راه رسمی این است که مجوز خاص `WRITE_SECURE_SETTINGS` را **یک‌بار، قبل از سرقت، از طریق کامپیوتر و ADB** به اپ بدهید:

```
adb shell pm grant com.example.antitheft android.permission.WRITE_SECURE_SETTINGS
```

اگر این مرحله را انجام ندهید، اپ در صورت خاموش بودن GPS فقط صفحه‌ی تنظیمات مکان را باز می‌کند (که نیازمند تایید دستی روی گوشی است — اگر گوشی دست سارق باشد، شاید این کار انجام نشود). این محدودیت امنیتی خود اندروید است و راه دور زدن قابل‌اطمینانی جز مجوز بالا ندارد.

برای دیتای موبایل هم اندروید مشابه محدودیت دارد؛ روشن/خاموش کردن برنامه‌ای بدون مجوز سیستمی ممکن نیست.

## 4. محدودیت‌های مهم

- **Google Play**: اپ‌هایی که از SMS receive/send استفاده کنند، معمولاً توسط پلی‌استور رد می‌شوند مگر اپ پیش‌فرض پیامک باشند. برای استفاده‌ی شخصی، APK را مستقیم روی گوشی نصب کنید (Sideload)، نیازی به پلی‌استور نیست.
- اگر گوشی سرقت‌شده کاملاً خاموش یا ریست فکتوری شود، این اپ (مثل هر اپ مشابهی) از کار می‌افتد.
- توصیه می‌شود موازی با این اپ، **Google Find My Device** را هم فعال نگه دارید؛ آن سرویس در سطح سیستم‌عامل کار می‌کند و حتی بعد از ریست تا حدی مفید است.

## 5. جریان کار برنامه (ردیابی نیمه‌زنده)

1. `SmsReceiver` پیامک ورودی را می‌گیرد و شماره‌ی فرستنده را با شماره‌ی ذخیره‌شده مقایسه می‌کند.
2. اگر متن پیامک برابر با `موقعیت` بود، `LocationService` با `ACTION_START_TRACKING` استارت می‌شود.
3. `LocationService`:
   - بررسی می‌کند GPS روشن است یا نه؛ اگر نه، تلاش می‌کند (طبق بخش 3) روشنش کند یا صفحه‌ی تنظیمات را باز می‌کند.
   - با `FusedLocationProviderClient.requestLocationUpdates` هر **۱ دقیقه** یک موقعیت تازه می‌گیرد.
   - هر بار لینک `https://maps.google.com/?q=lat,lng` را با `SmsManager` به شماره‌ی گیرنده پیامک می‌کند.
   - این کار ادامه پیدا می‌کند تا زمانی که پیامک `توقف` از همان شماره‌ی مجاز دریافت شود.
4. اگر پیامک `توقف` دریافت شود، `LocationService` با `ACTION_STOP_TRACKING` صدا زده می‌شود، آپدیت‌های موقعیت متوقف و یک پیامک تاییدیه («ردیابی موقعیت متوقف شد.») ارسال می‌شود.

### نکات درباره‌ی این نوع ردیابی

- چون ارسال با SMS انجام می‌شود، نیازی به دیتا/وای‌فای نیست — فقط آنتن لازم است.
- این یک نقشه‌ی زنده‌ی واقعی (real-time map) نیست؛ بلکه هر ۱ دقیقه یک پیامک/لینک تازه می‌رسد. برای نقشه‌ی واقعاً زنده (آپدیت پیوسته روی یک صفحه)، حتماً باید گوشی به اینترنت وصل باشد — چیزی که به‌طور خودکار قابل‌کنترل نیست (توضیح داده‌شده در بخش دیتا).
- ارسال هر ۱ دقیقه باتری را نسبتاً سریع مصرف می‌کند؛ برای استفاده‌ی طولانی‌مدت می‌توانید `UPDATE_INTERVAL_MS` در `LocationService.kt` را افزایش دهید.
- روی برخی گوشی‌ها (شیائومی، سامسونگ، هوآوی) اگر بهینه‌سازی باتری برای اپ خاموش نباشد، ممکن است سرویس بعد از مدتی توسط سیستم بسته شود.
